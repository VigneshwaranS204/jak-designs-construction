## 🛠️ Tech Stack & Architecture

- **Framework**: Next.js 16 (App Router)
- **Language**: TypeScript
- **Styling**: Tailwind CSS v4 with custom blueprint textures
- **Animation**: Framer Motion
- **Icons**: Lucide React
- **SEO**: Semantic HTML, OpenGraph, Twitter Cards, `robots.txt`, `sitemap.xml`, and Google `HomeAndConstructionBusiness` Schema JSON-LD.

## 🚀 Getting Started

### 1. Development Server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

### 2. Production Build
```bash
npm run build
npm run start
```
